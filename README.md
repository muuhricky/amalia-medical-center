# Amalia Medical Center

Landing page premium untuk klinik kesehatan **Amalia Medical Center** — desain boutique wellness dengan animasi interaktif.

## Tech Stack

- **Next.js 15** (App Router)
- **Tailwind CSS v4**
- **Framer Motion**
- **Lucide React**

## Fitur

- Custom interactive cursor (desktop)
- Hero dengan organic morphing blob reaktif terhadap mouse
- Magnetic button dengan spring physics
- Bento grid layanan dengan hover animations
- Scroll-triggered reveal animations
- CTA WhatsApp

## Menjalankan

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000)

## Kustomisasi

- Ganti nomor WhatsApp di `components/Hero.tsx`, `components/CTAFooter.tsx`, dan `components/Navbar.tsx`
- Tambahkan foto asli di `components/ExperienceSection.tsx` (ganti placeholder gradient)
